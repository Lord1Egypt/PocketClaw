## PicoClaw Core

PocketClaw vendors PicoClaw Core source into this repository at
[`core/src/`](core/src/) and builds the shipped Android arm64 binaries from it.
The vendored tree is upstream release `v0.3.1`, source commit
`2cf030d2fd3b871d7ec17e3be34c24688aac76da`, with PocketClaw modifications
applied on top — the Android active-network DNS integration, the provider
catalog extensions, model-discovery fixes, and the PocketClaw user-facing
wording.

Vendoring changes where the source lives. It does not change who wrote it:

    SOURCE LOCATION:      PocketClaw repository
    ORIGINAL PROVENANCE:  PicoClaw v0.3.1

- Upstream repository: <https://github.com/sipeed/picoclaw>
- Copyright: © 2026 PicoClaw contributors
- License: MIT. The upstream license file is preserved in place at
  [`core/src/LICENSE`](core/src/LICENSE) and reproduced at
  [`licenses/picoclaw-core-MIT.txt`](licenses/picoclaw-core-MIT.txt); the two
  are byte-identical.
- Per-file upstream copyright headers are preserved unmodified throughout
  `core/src/`.
- PocketClaw's divergence from upstream is recorded as a patch at
  [`core/pocketclaw-core-v0.3.1.patch`](core/pocketclaw-core-v0.3.1.patch) and
  is regenerated by `core/regen-upstream-patch.sh`. Nothing upstream-authored
  is claimed as PocketClaw's own work; the patch lists exactly the 52 files
  PocketClaw changed, of which 13 are new PocketClaw-authored files.
- The binary provenance and hashes are in
  [`UPSTREAM_BASELINE.md`](UPSTREAM_BASELINE.md).

Two upstream paths are deliberately not vendored, neither of which is a build
input: `assets/` (upstream README screenshots and marketing media) and
`pkg/seahorse/.omc/` (an upstream developer's tool-state file, committed by
accident, containing no code).

Go module dependencies of the vendored Core are resolved through
`core/src/go.mod` and `core/src/go.sum` and are governed by their own upstream
licenses. They are not vendored into this repository.

Flutter and Android dependencies are governed by their own upstream licenses,
as resolved through `pubspec.lock` and Gradle dependency metadata. No final
license has been selected for newly authored PocketClaw code.

## PocketClaw-authored identity assets

`assets/branding/pocketclaw-mark.png` is an original PocketClaw identity asset
generated for this repository from a non-derivative design brief. The selected
second mark is the primary visual direction; its launcher, adaptive, splash,
and monochrome notification variants preserve that identity. It is not a
PicoClaw/FUI image and does not remove or replace the upstream notices above.
